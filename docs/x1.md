# X1 Mainnet

X1 is a production SVM Layer-1 (X1 Labs, founder Jack Levin) that forked
the Solana stack into its own client, **Tachyon** (an Agave-lineage fork,
v4.0.x on mainnet). Mainnet launched **October 6, 2025**. Its whole pitch
is the one this repo is built on: **Solana code works unchanged** — same
JSON-RPC wire format, same account model, same Anchor toolchain.

That makes X1 the cheapest possible second production chain for Clawd
Chain: the read layer in `api/lib/read.js` already speaks X1 for every
shared program, and this repo now registers X1 as a first-class chain in
`api/lib/chains.js` alongside Clawd Chain and Solana mainnet.

## Chain facts (verified by live probe, 2026-11-07)

| | |
|---|---|
| RPC | `https://rpc.mainnet.x1.xyz` (env: `RPC_X1`) |
| WebSocket | `wss://rpc.mainnet.x1.xyz` |
| Genesis hash | `4SvBP3omtvcCVWdxq1zBY5cDp4wndjsThb6nEMn6iMdN` |
| Client | Tachyon 4.0.4 (`solana-core: 4.0.4`) |
| Native token | **XNT** — gas + staking, **9 decimals** (SOL-style lamports; verified by supply arithmetic against `getSupply`) |
| Supply | ≈1.084B XNT total / ≈43M circulating (~92% staked) |
| Explorer | <https://explorer.x1.xyz> |
| Docs | <https://docs.x1.xyz> |
| Slot time | ~400 ms; 216,000-slot epochs on the mainnet-consistent backend |

Programs that run on X1 mainnet **at exactly their Solana addresses**:
Squads v4, Metaplex Token Metadata, Metaplex Core, Candy Machine v3, SPL
Token and Token-2022 (identical). Clawd's own programs (agent identity,
agent tools, genesis, shield) do **not** exist on X1 — decoders for them
stay Clawd-only.

Notable X1 differences from Solana mainnet: EIP-1559-style dynamic base
fee with local fee markets, free validator votes, dramatically cheaper
rent, and Token-2022 **confidential transfers live** via X1 Privacy
(cXNT / cUSDC.x). The Warp Bridge carries assets Solana ↔ X1 (USDC
arrives as bridged **USDC.x** — a bridge trust assumption, not native
Circle USDC; XNT itself crosses to Solana as wXNT).

## Connect

Standard Solana web3.js — no X1-specific SDK needed:

```js
const { Connection, clusterApiUrl } = require('@solana/web3.js');

// X1 mainnet
const x1 = new Connection(process.env.RPC_X1 || 'https://rpc.mainnet.x1.xyz', 'confirmed');
console.log(await x1.getBlockHeight());
console.log(await x1.getGenesisHash()); // 4SvBP3omtvcCVWdxq1zBY5cDp4wndjsThb6nEMn6iMdN

// Solana mainnet via the operator's Alchemy endpoint (keep the URL in env, never in code)
const solana = new Connection(process.env.ALCHEMY_RPC_URL, 'confirmed');
```

Or use the registry in `api/lib/chains.js`, which is what the omnichain
agent in `agent/` does:

```js
const { getChain, rpcCall, fingerprint } = require('../api/lib/chains');
const x1 = getChain('x1');
const height = await rpcCall(x1.rpc(), 'getBlockHeight');
const print = await fingerprint('x1'); // see the caveat below — always check the verdict
```

## ⚠️ The load-balancer caveat (read this before trusting a read)

The public hostname `rpc.mainnet.x1.xyz` is a regional load balancer
fronting **two divergent backend families** with different chain views
(observed 2026-11-07, seconds apart, same hostname):

| | Family B — mainnet-consistent | Family A — divergent |
|---|---|---|
| `feature-set` | `3075748243` (matches Tachyon cluster nodes) | `2223655621` |
| `slotsInEpoch` | `216000` | `432000` |
| `getSupply` | full result (≈1.084B XNT) | error `-32002` |
| Block height | ≈90.9M (consistent with external counts) | ≈105.7M (irreconcilable) |

A single RPC session can silently mix both views. What Family A actually
is remains unverified; its existence behind the production hostname is
itself the finding.

**Rules for building on X1 from this repo:**

1. **Fingerprint every session** — `fingerprint('x1')` in
   `api/lib/chains.js` compares `feature-set` + `slotsInEpoch` against
   both known families and returns a verdict.
2. **Reads off the public LB are best-effort.** Fine for dashboards,
   explorers, and the demo agent — labeled as such everywhere they
   surface.
3. **Never settle payments or assert finality against the public LB.**
   Settlement-grade work needs a pinned, fingerprinted node (our own
   Tachyon node, or a dedicated endpoint from X1's infra providers).

## The omnichain agent

`agent/` contains a small read-only Node agent that reads across all
three registered chains — Solana mainnet via Alchemy, X1 via the public
RPC with a fingerprint check on every call, and Clawd Chain — and loads
the **X1 Agent Skills** pack (`x1wealth/x1-agent-skills`, Apache-2.0) as
its skill pack. See `agent/README.md`.
